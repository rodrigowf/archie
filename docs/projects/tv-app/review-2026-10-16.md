# Archie TV — code review triage (2026-10-16)

Two read-only reviews of `feat/tv` (after T0–T4): (A) shared voice/audio modules, TV voice, TV
control, backend, setup script; (B) TV UI. **No regression in `:app-main` / `:app-lite`** (A checked
every shared-module default path). All findings below were accepted unless marked.

## Backend + setup → fix pass `feat/tv-fix-be`

| # | Finding | Fix |
|---|---|---|
| A2 | Cast falls back to adb when the TV *refuses* ("Allow agents to open pages" off) | refusal carries `code:"refused"` → `{ok:false, via:"app"}`, no adb; command endpoint → 403 |
