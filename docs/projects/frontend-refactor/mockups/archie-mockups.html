Archie redesign mockups

One Material 3 product across the desktop web app, phones (the Android app and mobile web are the same screens), the iPad mini, and the A300M lite app. Every color, radius and type size comes from design/tokens. Static screens for approval before implementation; tool groups, tool cards, tabs and the composers respond to clicks.

1

Desktop web

Expanded, 840 dp and up. Frame 1280 × 1040. Rail, list pane and workspace sit on two surface tones; nothing is separated by a border or a tinted strip.

Stream order is keptThe earlier "3 steps" group collapsed when text followed it. The latest group is expanded here because it was just clicked; it collapses on its own once the next text arrives.
Every tool card shows outputRead shows lines, Grep shows matches, Edit shows a diff with +/− counts, Bash shows output and exit code. Click a card header to fold it.
One composer＋ (attach, voice message, slash commands), field, context ring (tap to compact), mic, and the primary button. Clear the field to see the primary button change state.
2

Phone

Compact, below 600 dp. Frames 412 × 915. These screens are the Android app and mobile web; only the system status bar differs. No bottom navigation bar: the conversation is home, the drawer and session switcher are one tap away.

3

Tablet · iPad mini 2

Medium, 600–839 dp. Frame 768 × 1024, served by the compat build. The rail stays, the list pane becomes an overlay (closed here), and the tab overflow menu takes over sooner.

List pane as an overlay☰ on the rail (or a rail destination) slides the list pane over the workspace with a scrim. Closed by default, so the conversation gets the full 688 dp.
Earlier tab overflowTwo and a half tabs fit; the 4 ⌄ counter covers all open tabs and opens the searchable list.
Visuals inlineA visual Archie made shows as a card with Open and Show on TV, the same action as the full-screen top bar.
Safari 12No new CSS features here: tokens are plain custom properties, tone separation needs no color-mix, and gaps degrade to margins in the compat build.
Composer at restArchie conversation, empty field: primary button is Voice. Type to see it become Send.
4

Lite app · Samsung A300M

540 × 960, Android 5, plain Views. One voice-first "state face" meant to be read from across the room: big state shape, one word, the last exchange as large captions, a connection dot and a settings button.
