Checked:

- Inline formatting in paragraphs, lists, quotes and table cells (bold, italic, code, links,
  strikethrough); no literal `**` or backticks on compat.
- Tables: alignment, escaped pipe, wide table scrolls inside its own container, no page-level
  horizontal scroll (`scrollWidth == innerWidth` at 412 and 768).
- Task lists (checked/unchecked/nested), GFM autolinks (URL, www, email, parens, trailing dot,
  `/`-preceded email not linked), footnotes.
- Code blocks: python/ts/markdown highlighted; fence without a language, indented code and an
  unknown language render as plain blocks with a Copy button; mid-stream fences are plain.
- Compat: 36/36 eligible blocks highlighted (deferred, `html.low-end`), no console errors; Copy
  shows "Copied" through the textarea fallback (`?caps=compat` disables the Clipboard API).
- Memory document: frontmatter folded into a summary chip; relative `.md` links handled in-app.

Bundle check with the markdown stack included (same scratch builds):

- `scan-compat-bundle.mjs`: PASS, 0 errors (11 dynamic-RegExp warnings from highlight.js core,
  find-and-replace, to-markdown and core-js; 1 pre-existing allowlisted core-js probe). The fork's
  boundary-group regex is in the compat bundle; the stock lookbehind is not.
- Budgets: main initial JS 99.8 kB, largest lazy 44.2 kB (highlighter); compat initial JS
  110.3 kB, largest lazy 38.6 kB, total 192.9 kB. All within limits.
